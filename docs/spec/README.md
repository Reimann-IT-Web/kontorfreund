## Regeln

- Keine Inhalte anderer Produkte: keine Screenshots, Masken, Texte oder Vorlagen. Funktionen werden in eigenen Worten beschrieben.
- Rechtliche Anforderungen nennen ihre Quelle (Gesetz, Norm), damit sie prüfbar sind.
- Jede Funktion hat eine Nummer und Abnahmekriterien; daraus werden Tests.
- Die Dateien für spätere Phasen werden vor Beginn der Phase verfeinert und erneut freigegeben.
